⚙ GitHub publishing setup (one-time) Not set up
  1. Go to github.com/settings/tokens (sign in or create a free account)
  2. Scroll down, click Generate new token (classic)
  3. Check the repo checkbox (full control of private repos)
  4. Click Generate token at the bottom
  5. Copy the token (starts with ghp_) and paste it below

Classic tokens expire. If your old token stopped working with a "Bad credentials" error, it probably expired — just generate a new one above and paste it below, then click Save token. You can also use a fine-grained token (starts with github_pat_) with Contents: Read & Write + Pages: Read & Write + Administration: Read & Write permissions.

Your token is stored only in this browser (localStorage). It never leaves your computer except to talk directly to GitHub. You only do this once — until the token expires, then repeat the steps above.

How to format each question: Start with Q: then the question. List 4 options as A) B) C) D). Mark the correct one with a * after the letter (e.g. C)*). Add WHY: with a short explanation. Separate questions with a blank line.

Example: 

Q: Which prayer is prayed at the beginning of every service?
A) The Lord's Prayer
B) The Litany of the Departed
C)* The Thanksgiving Prayer
D) The Absolution
WHY: The Thanksgiving Prayer starts every service: Vespers, Matins, Liturgy, weddings and funerals.

Q: How many tunes does the Verses of Cymbals have?
A)* Three
B) Four
C) Five
D) Two
WHY: Three: the standard tune, the festive tune, and the Lenten Kyrie eleison.
